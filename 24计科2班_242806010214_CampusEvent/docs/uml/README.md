# UML 图目录与版本规范

> 本目录存放实验二的用例图、类图、时序图等 UML 产物。
> 版本分界：教师发布变更请求（CR）前为一个主版本段（v1.x），CR 发布并完成影响评估后进入 v2.x。

## 1. 版本规则

| 阶段 | 触发 | 版本 | 对应 Git 标签 |
|---|---|---|---|
| 阶段 A：CR 前基线 | 初始设计、评审修改、初版实现 | v1.0、v1.1、v1.2…… | baseline-v1 |
| 阶段 B：CR 后变更 | 教师发布 CR、完成影响分析并开始修改 | v2.0、v2.1…… | change-v2 |

- 评审意见导致的修改：minor +1（v1.0 → v1.1），旧文件保留。
- CR 后：从当前 v1.x 复制生成 v2.0 再修改，**不覆盖** v1.x，保留两版对照证据（指导书 3.8 要求初版与变更版 UML）。
- 每次升版同步更新图内版本说明与本文件索引。

## 2. 命名与导出

- 文件命名：图种类 + 版本，例如 use-case-v1.0.drawio、class-diagram-v1.0.drawio、sequence-signup-v1.0.drawio、sequence-approval-v1.0.drawio。
- 页面名与图内标题必须含版本号；图内右下角注明：版本、日期、阶段、对应 Git 标签。
- 需要给报告/PPT 用时，从 DSH 右侧画板导出同名 PNG（2x）或 SVG，不手工改图。
