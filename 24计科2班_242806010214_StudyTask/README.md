# StudyTask · 个人学习任务管理系统

> 《软件工程》实验一 ｜ 24 计科 2 班 · 242806010214 ｜ 项目代号：StudyTask ｜ 状态：初始化
> 需求来源：实验指导书附录 A《StudyTask 需求规格说明书》

## 1. 项目概述

单用户、本地运行的 Web 应用，用于记录课程作业、实验、考试准备等学习任务。目标用户为单个在校大学生，数据保存在本地 SQLite 数据库中。

## 2. 功能范围

| 编号 | 功能 | 验收重点 |
| --- | --- | --- |
| P1-F01 | 新建任务（名称、课程、描述、截止日期、优先级） | 必填项校验，正确保存 |
| P1-F02 | 查看、编辑、删除任务 | 操作结果可见，删除须二次确认 |
| P1-F03 | 任务状态：待完成 / 进行中 / 已完成 | 变更后持久保存 |
| P1-F04 | 按课程、状态、优先级筛选 | 筛选结果准确 |
| P1-F05 | 按截止日期识别逾期与即将到期 | 日期逻辑正确 |
| P1-F06 | 统计总数、完成数与完成率 | 统计结果正确 |
| P1-F07 | 本地持久化 | 重启服务后数据仍存在 |

**范围外**（按附录 A.5 明确不做）：账号注册与多用户权限、共享任务、邮件/短信推送、第三方日历同步、移动端 App、云部署。

## 3. 技术方案

- Python 3.11+、Flask、SQLite（指导书推荐技术边界）
- 测试：pytest
- 版本控制：Git / GitHub

> 内部类结构与数据库表结构由 AI 在实现阶段设计，学生不预先指定（实验一实施要求）。
