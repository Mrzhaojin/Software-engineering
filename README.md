## 通用规范（摘自实验指导书）

- **可用 AI，但必须可验证**：AI 生成的设计、代码与测试均为待验证输出，不以 AI 声称“完成”替代验收。
- **过程可追踪**：每个项目保留 `AI_DEV_LOG.md`，记录关键提示词、设计决策、问题与人工判断（5–10 条代表性事件）。
- **版本可追溯**：用 Git 保存关键版本；实验二至少包含 `baseline-v1` 与 `change-v2` 两个标签。
- **安全与诚信**：不提交 `.env`、token、密钥或真实敏感数据；不虚构测试通过率、运行截图或工具执行结果。
- **交付完整**：源代码、`requirements.txt`、从零可复现的 `README.md`、测试与实验报告齐全。
